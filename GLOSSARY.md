# Brain-Dump

Brain-Dump gets the things worked out during the week, especially inside AI dev sessions, into the Obsidian Vault before they are lost.

## Language

**Vault**:
The single Obsidian vault Brain-Dump writes into; the user's second brain.
_Avoid_: Notebook, knowledge base

**Dump**:
One raw captured item (a thought, a session excerpt, a link) not yet organised into the Vault's structure.
_Avoid_: Capture, entry, snippet

**Item**:
One entry in a Dump: a Learning, a Decision or a Todo.
_Avoid_: Entry, line, bullet

**Learning**:
An Item recording something found out during a Session.
_Avoid_: Insight, fact, note

**Decision**:
An Item recording a choice made during a Session, together with its Rationale.

**Rationale**:
The reason a Decision was made.
_Avoid_: Justification, why

**Todo**:
An Item recording an action still to be taken.
_Avoid_: Task, action item

**Session**:
One interaction with an AI tool that a Dump is drawn from, whether a coding agent run (Claude Code, Codex) or a chat app thread (Claude web, ChatGPT, Gemini).
_Avoid_: Conversation, chat, thread

**Inbox**:
The place in the Vault where Dumps land before Filing.
_Avoid_: Queue, staging

**Filing**:
Turning a Dump into structured notes: titled, tagged, linked, and merged into a Topic Note or Weekly Note or made into a new note.
_Avoid_: Processing, organising, triage

**Filing Plan**:
The proposed destination for every Item in one Dump, approved or adjusted by the user before anything is written.
_Avoid_: Proposal, preview

**Curated Note**:
Any note in the Vault outside the Inbox; it changes only through an approved Filing Plan or other approved plan.
_Avoid_: Curated zone, permanent note

**Weekly Note**:
The per-week note holding that week's updates, to-dos, blockers, notes and key takeaways.
_Avoid_: Weekly update, journal

**Todo Group**:
A plain bullet in a Weekly Note's to-do section that gathers the week's Todos for one project or kind of work (e.g. "Dissertation", "Workshop papers"); groups can nest inside groups.
_Avoid_: Header bullet, category, heading

**Topic Note**:
A durable note about one subject being researched or worked on.
_Avoid_: Page, wiki note

**Project Note**:
The main note for one project, whatever its title (e.g. "Context Bridge MCP Main Note", "Virtual Assistant Project").
_Avoid_: Index, main note

**Route**:
A remembered mapping from a project or subject to the note or Todo Group Filing should target, learned from the user's redirects.
_Avoid_: Rule, mapping, alias

**Consolidation**:
Distilling a long Topic Note or Project Note into a Digest, without changing or removing any of the note's existing text.
_Avoid_: Tidy, cleanup, rewrite

**Digest**:
The summary Consolidation produces for a note, linking back to the Items it distils.
_Avoid_: Summary, rollup
