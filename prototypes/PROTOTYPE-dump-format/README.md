# PROTOTYPE: Dump file format (throwaway)

Answers [What does a Dump file look like?](https://github.com/ChrisKalahiki/Brain-Dump/issues/4). There are three variants, all with the same content: a Dump of the 2026-10-05 Brain-Dump planning Session.

- `A-sections/`: H2 sections per kind, with rationale as a nested bullet.
- `B-callouts/`: one Obsidian callout per item.
- `C-tagged-lines/`: a flat checklist; kind is an inline tag and Filing ticks items off.
- `D-chosen/`: C's checkboxes under A's headings; `#todo` only; branch in the Session line.

Delete once the ticket is resolved.
