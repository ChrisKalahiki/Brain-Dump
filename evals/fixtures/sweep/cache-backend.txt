[2026-09-29 14:44] User:
Ugh. What's the fix?

[2026-09-29 14:46] Assistant:
In the default rollback-journal mode a writer blocks readers. Setting `PRAGMA journal_mode = WAL` once on open lets readers run while one process writes, and `PRAGMA busy_timeout = 5000` makes a second writer wait up to 5 seconds instead of failing straight away. WAL mode persists in the database file, so it only needs setting once, but setting it on every open is harmless.
